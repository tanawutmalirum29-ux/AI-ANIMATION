# ประตู พื้น และตำแหน่งตัวละคร — Revision 4

แก้ปัญหาประตูสูงเกินคน ตัวละครดูยืนลอย และการสลับตำแหน่งระหว่างฉากในตัวอย่างโรงเรียน 12 ฉาก โดยใช้ภาพเรนเดอร์และไฟล์ JSON รุ่นก่อนเป็นข้อมูลตรวจ

- ประตูเดิมสูง 41–45 หน่วย เทียบกับคนสูงประมาณ 23–25 หน่วย ประตูรุ่นนี้สูง 30.5 หน่วย กว้าง 11 หน่วย ขนาดคงที่เมื่อเปลี่ยน 9:16 เป็น 16:9 และขอบล่างตรงกับพื้นห้อง ลูกบิดและแขนใช้ตำแหน่งประตูชุดเดียวกับที่วาด
- `actors[].ground = {mode: 'surface', lane: 0.6}` ผูกพื้นรองเท้าจริงกับพื้นฉากหรือขั้นบันได คำนวณทั้งสองเท้าและมุมรองเท้า ให้มีจุดรองรับอย่างน้อยหนึ่งจุดและไม่จมใต้พื้น เงาสัมผัสอยู่ที่จุดรองรับ ขนาดตัวละครไม่เปลี่ยนเพราะเดินขึ้นบันไดหรือเปลี่ยนสัดส่วนจอ
- ตัวละครที่ไม่ได้ตั้ง `ground.mode` ใช้ตำแหน่งเดิม ส่วนท่ากระโดด นอน และนั่งไม่ถูกบังคับให้ติดพื้น วิธีนี้ยังไม่ใช่ระบบฟิสิกส์เต็มรูปแบบหรือการล็อกเท้ากับตำแหน่งแนวนอนตลอดก้าว
- ฉาก 5 ให้นนท์เข้าห้อง ปิดประตู แล้วเดินไปตำแหน่งเริ่มดันโต๊ะในฉาก 6 ครูกับมายด์หลบเส้นทางโต๊ะ ฉาก 9→10 ให้นนท์ถอยและครูเดินเข้าหาลูกบิดก่อนใช้กุญแจ ฉาก 11→12 เริ่มที่ตำแหน่งเดิมก่อนค่อย ๆ ถอยจากประตู
- เครื่องมือซ่อมงานเดิมอัปเกรด revision 3 เป็น 4 ได้ ทั้งรหัสดั้งเดิมและตอนที่เพิ่มจากปุ่มบทปรับปรุง โดยเก็บเสียง บท ระยะเวลา โปรไฟล์เสียงและตัวละครเดิม แสดงรายการก่อนใช้และ Undo ได้

ไฟล์หลักคือ `examples/taweetha-zombie-siege.json` เป็นโปรเจกต์พร้อมฉาก ตัวละคร บทพากย์และคำบรรยาย เปิดผ่านเมนูเปิดไฟล์โปรเจกต์ได้ สคริปต์ `python scripts/refine-school-story.py` สร้างตัวอย่างซ้ำได้โดยไม่แตะโปรเจกต์ที่ผู้ใช้เก็บในเบราว์เซอร์

การตรวจเพิ่มใน `tests/school-motion-browser.cjs` วัดพื้นรองเท้า 1,326 ตัวอย่างเวลา และสัดส่วนคนต่อประตู 38 กรณีในภาพ 9:16 และ 16:9 ตรวจมือเอื้อมลูกบิดและโต๊ะตลอดช่วงใช้งาน ร่วมกับการตรวจจับพร็อพ เวลาเสียง Undo และการส่งออกจริง ส่วน `tests/motion-runtime.test.cjs` ตรวจตำแหน่งต่อเนื่องข้ามฉากและการอัปเกรดตอนที่เปลี่ยนรหัสแล้ว

รัน:

```sh
node --test tests/motion-runtime.test.cjs
node tests/taweetha-zombie-smoke.cjs
node tests/school-motion-browser.cjs
SCHOOL_RENDER_VIDEO=1 node tests/school-motion-browser.cjs
```

การเรนเดอร์ CI เป็นหลักฐานด้านภาพแบบไม่มีเสียง หากระบุ `SCHOOL_NARRATED_PROJECT` จะใช้ไฟล์เสียงจริงจากโปรเจกต์นั้นโดยไม่แก้ข้อความพากย์เพื่อหลบการตรวจเสียง
