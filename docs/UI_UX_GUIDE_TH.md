# การเริ่มต้นใช้งานและการแบ่งพื้นที่

หน้าเริ่มต้นเป็นค่าเริ่มต้นของเว็บ มีปุ่มหลัก “เปิดพื้นที่ตัดต่อ” และปุ่มรอง “เปิดไฟล์โปรเจกต์” การกลับหน้าหลักไม่ล้างโปรเจกต์ ปุ่มเปิดไฟล์ใช้ระบบนำเข้าเดิม

| พื้นที่ | เริ่มต้นอย่างไร | เครื่องมือ |
| --- | --- | --- |
| หน้าหลัก | เลือกทำงานต่อหรือเปิดไฟล์ | สรุปโปรเจกต์และขั้นตอน 1–3 |
| ฉากและภาพ | เลือกฉาก ตรวจพรีวิว แล้วเพิ่มตัวละคร | ฉาก / ตัวละคร / ไลบรารี |
| เสียง | อัดเสียง เลือกโทน และจัดคลิป | พากย์ทันที / โทนเสียง / ไทม์ไลน์เสียง |
| ตรวจและส่งออก | ตรวจงาน ดูพรีวิว แล้วเลือกรูปแบบ | AI ตรวจงาน / ส่งออก |
| ผู้ช่วย AI | เลือกงานและตรวจผลก่อนใช้ | ใช้พื้นที่ AI เดิมตามสิทธิ์บัญชี |
| ผู้ดูแลระบบ | เข้าจากหน้าหลักด้วยบัญชีแอดมิน | AI ครู / ชุดสอน JSON / ประวัติ |

เครื่องมือเดิมยังใช้ DOM IDs, ข้อมูลโปรเจกต์, undo และ API เดิม ตัวเลือก Motion/ซับ/ป้ายอยู่ใน “ตัวเลือกพรีวิว” ส่วนคำสั่งโปรเจกต์ยังอยู่ในเมนูด้านบน การแบ่งเมนูเป็นเพียง UX; การอนุญาตเรียก API ยังตรวจโดย AWS เช่นเดิม ไม่มีปุ่มให้ผู้ใช้เปลี่ยนสิทธิ์ตนเอง

บนจอเล็กการ์ดหน้าเริ่มต้นเรียงหนึ่งคอลัมน์ หมวดเครื่องมือแบ่งเป็นปุ่มย่อยพร้อมคำอธิบาย ใช้ `?workspace=editor` เพื่อเปิดพื้นที่ตัดต่อโดยตรงสำหรับบุ๊กมาร์กหรือ automated tests

ตรวจด้วย `node tests/navigation-ux-smoke.cjs` (ต้องมี Playwright และ Chromium) ครอบคลุม 320, 390, 768, 1024, 1440 และ 1920 พิกเซล การสลับพื้นที่และการแสดงสิทธิ์แบบจำลอง ไม่ใช่การทดสอบ backend จริง
