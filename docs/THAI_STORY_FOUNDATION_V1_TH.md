# Thai Story Editorial Foundation v1 — ชุดฝึกพื้นฐานภาษาไทย

## ผลงาน
- ข้อมูลต้นฉบับ **75 ตัวอย่าง (15 เรื่อง × 5 ทักษะ)** เก็บใน `training-lab/datasets/thai-narrative-editor-foundation-v1.json`
- แนวเรื่อง 15 แบบ เช่น ตลาดน้ำท่วม ประภาคาร หมอกภูเขา โรงพยาบาล สถานีรถไฟ พิพิธภัณฑ์ โรงเรียน ไซไฟ ปราสาท งานเทศกาล และหุ่นยนต์
- ข้อมูลแต่ละแถวมี `previous`, `original`, `revised`, `next`, `issue`, `reason`, `group`, `genre`
- ทักษะ 5 ประเภทที่สมดุลกัน: `continuity` (เหตุ–ผล), `clarity` (สรรพนาม/ความชัดเจน), `expand` (เติมสะพานเชื่อม), `pacing` (กระชับบท), `keep` (ไม่ควรแก้)
- **ทุกตัวอย่างเขียนขึ้นใหม่เพื่อการสาธิตโดย AI** ไม่ได้มาจากผู้ใช้ ไม่ใช่บทที่เจ้าของอนุมัติ ไม่ได้คัดลอกบทความหรือนิยายผู้อื่น

## การฝึกที่ทำจริง

โมดูล `studio-story-foundation.js` ฝึก **multinomial Naive Bayes ด้วย CPU** จากตัวอักษรภาษาไทย 2–3 ตัวเรียงกัน และรูปแบบข้อความบางอย่าง ไม่มี GPU และไม่เรียก API เพื่อฝึก

`node training-lab/train-story-foundation.cjs` จะวัดผลซ้ำได้โดย:
1. ตรวจทุกตัวอย่างและป้ายกำกับ
2. แยกกลุ่มเป็นชุดฝึกและทดสอบโดย **เรื่อง** ป้องกันฉากในเรื่องเดียวกันรั่วไปอยู่ทั้งสองชุด
3. ใช้ 12 เรื่อง (60 ตัวอย่าง) ฝึก และ 3 เรื่อง (15 ตัวอย่าง) ทดสอบ
4. แสดง accuracy บนชุดข้อมูลสังเคราะห์ และ baseline แบบทาย label ที่พบบ่อยที่สุด
5. โมเดลในเว็บจะ fit จากตัวอย่างทั้งหมดหลังการประเมินเพื่อใช้ **แนะนำประเภทปัญหาเท่านั้น**

**สำคัญ:** ผลการทดสอบกับข้อมูลสังเคราะห์ไม่ได้รับประกันประสิทธิภาพกับบทเรื่องจริง ขนาดชุดทดสอบเล็ก ตัวเลขไม่ได้สอบเทียบเป็นความน่าจะเป็น และยังไม่ถือว่าเป็นโมเดลภาษาใหญ่/นักเขียนบทโดยอัตโนมัติ

## ใช้ในเว็บอย่างไร

เปิด `AI ครู / API → ต่อเติมบท` แล้วเลือกฉากและกด **AI ลูกตรวจบริบท**

- เว็บดึง JSON ชุดข้อมูลฝึกที่ Deploy มากับ Amplify แล้วใช้ CPU ฝึกโมเดลขนาดเล็กในเบราว์เซอร์ (1 ครั้งต่อ session)
- AI ลูกแสดงประเภทปัญหาที่สงสัย คะแนนชุดทดสอบข้ามเรื่อง และตัวอย่างบทเดิม/บทแก้ใกล้เคียงกัน
- ถ้ากด **AI แม่เสนอแก้** จะส่งตัวอย่าง **ที่คุณอนุมัติจาก AWS สูงสุด 2 ตัวอย่าง** และ **ตัวอย่างสังเคราะห์สูงสุด 1 ตัวอย่าง** ให้แยกแหล่งข้อมูลชัดเจน ไม่ส่งคลังทั้งหมดหรือแกล้งอ้างว่าเป็นบทของคุณ
- AI แม่เสนอบทแก้ ผู้ใช้ต้องตรวจและยืนยันก่อนใช้ในโปรเจกต์หรือบันทึกเป็นบทเรียน AWS
- AI ลูกไม่เปลี่ยนบทโดยอัตโนมัติ ไม่สร้างข้อเท็จจริงใหม่เอง ไม่ถือว่าคำตอบของ AI แม่ถูกต้องทุกครั้ง

## ขั้นถัดไป

เก็บตัวอย่าง **จากบทเรื่องจริงที่คุณตรวจและอนุมัติ** ใน DynamoDB แยกจากตัวอย่างชุดนี้ เพื่อตั้งชุดประเมินมนุษย์ ตรวจปัญหาของเรื่องที่ไม่เคยพบ และวัดผลจริงก่อนยกระดับโมเดลทักษะภาษาในอนาคต

## ทดสอบและติดตั้ง

```bash
node --test tests/story-foundation-cpu.test.cjs
node training-lab/train-story-foundation.cjs
```

ชุดข้อมูลและโมเดลฝั่งหน้าเว็บจะ Deploy ตาม `main` ผ่าน Amplify อัตโนมัติ ไม่สร้างทรัพยากร AWS ใหม่และไม่เพิ่มค่าเรียก AI แม่ตอนวิเคราะห์ขั้น CPU ส่วนโหมด AI แม่ยังอาศัย Lambda `student.storyLessons` ที่เพิ่มไว้ใน PR #88 หาก AWS ยังไม่อัปเดต PR #88 ต้อง Deploy Lambda ตามคู่มือเดิมก่อน
