# สอน AI ลูกอัตโนมัติ — JSON → AI ลูก → AI แม่ → AWS

## วิธีใช้งาน (สองขั้นตอน)

1. เข้า AI-ANIMATION แล้ว **นำเข้า JSON ตามปกติ**
2. เปิด **AI ครู / API → คุย / สั่งงาน**
3. กด **1. AI ลูกตรวจทั้ง JSON** เพื่ออ่านบทพากย์จากทุกตอน ตรวจคำซ้ำ จับบริบทก่อนหน้า/ฉากถัดไป และใช้โมเดลภาษาไทย CPU ให้คำแนะนำเบื้องต้น **ไม่เรียก AI แม่และไม่ใช้โควตา API เพื่อวิเคราะห์**
4. กด **2. AI แม่สอนและบันทึก AWS** หรือกดปุ่มลัด **สอน AI ลูก** ระบบจะเรียก AI แม่ผ่าน API ที่เชื่อมไว้ วิเคราะห์ฉากเป็นชุดละไม่เกิน 3 ฉาก พร้อมเหตุผลว่าควรเก็บ/แก้/ขยายและส่งเก็บใน DynamoDB *โดยไม่ต้องกดอนุมัติแต่ละฉาก*
5. ดูสถานะบนหน้าเว็บ เช่น สำเร็จกี่ฉาก ใช้บทเรียนเดิมกี่ฉาก และยังไม่สำเร็จกี่ฉาก หากเน็ตหลุดกดสอนซ้ำได้ บทเรียนเดิมที่ AWS บันทึกแล้วจะถูกค้นคืนเพื่อหลีกเลี่ยงการเรียกโมเดลซ้ำ

**คุณยังต้องเชื่อม provider API ที่ใช้งานได้ก่อน** โควตา/ราคาและนโยบายของผู้ให้บริการยังมีผลตามจริง การประมวลผลทุกฉากของเรื่องยาวอาจใช้เวลาหลายรอบ (พัก 11 วินาทีต่อชุดเพื่อเลี่ยง limit 6 calls/minute) ต้องเปิดหน้าเว็บและให้อินเทอร์เน็ตทำงานจนเห็นผลสุดท้าย หากปิดหน้ากลางคัน กระบวนการเบราว์เซอร์จะหยุด แต่บทเรียนที่ AWS ยืนยันว่าเก็บแล้วไม่หาย

## ความจำอัตโนมัติอยู่ตรงไหน

ใช้ DynamoDB ตารางเดิม `story-studio-teacher-feedback` ใน partition `learning#teacher-story-coherence` key `teach#SHA256(canonical source scene)` สำหรับป้องกันการเขียนซ้ำ/เรียก API ซ้ำในเนื้อหาเดิม

แต่ละบทเรียนมี:
- ข้อความก่อนแก้/หลังแก้ บริบทข้างเคียง ประเภทปัญหา เหตุผล AI แม่ ฉาก ตอน และโมเดล
- `source: teacher-auto-unverified`
- `reviewedByOwner: false`, `usedForWeightTraining: false`
- สถานะ `teacher-reviewed-unverified`

**แยกจาก** `learning#story-coherence` ที่คุณตรวจและอนุมัติเอง และ `learning#thai-repetition-intent` ที่ใช้ฝึกน้ำหนักโมเดลคำซ้ำ

ข้อมูลที่ AI แม่สอนอัตโนมัติจะอ่านกลับมาเป็น **ตัวอย่างประกอบการพิจารณา (retrieval/few-shot)** ในหน้า “ต่อเติมบท” ครั้งต่อไป แต่ยังไม่ได้เปลี่ยนน้ำหนักโมเดลภาษาไทยหรืออนุมัติให้สร้าง/เผยแพร่บทจริงเอง

## ขอบเขตการทำงานที่ถูกต้อง

- ดำเนินการตั้งแต่ตรวจบทจนบันทึกบน AWS อัตโนมัติได้เมื่อเปิดหน้าไว้ และ API เชื่อมต่อได้
- **ไม่แก้ JSON ต้นฉบับโดยไม่ถาม** เพราะ AI แม่ยังอาจแต่งเรื่องผิด/เปลี่ยนเจตนาผู้เขียน; ข้อเสนอเก็บเป็นบทเรียน unverified ก่อน
- ไม่มีการบันทึกเป็นชุดฝึกที่มนุษย์รับรองโดยอัตโนมัติ (ลดการฝึกซ้ำกับข้อผิดพลาดของโมเดล)
- ไม่เรียก fine-tuning / LoRA / LLM weight update อัตโนมัติ — ระบบนี้คือการสร้างความจำที่ค้นกลับมาใช้ได้ ไม่ใช่การฝึกน้ำหนัก Generative AI
- ข้อมูลต้นฉบับยาวกว่า 1,200 ตัวอักษรต่อฉากหรือ ID ซ้ำจะถูกข้ามพร้อมจำนวนแจ้ง ไม่ตัดสั้นแล้วอ้างว่าได้ตรวจทั้งฉาก
- แต่ละ batch เรียก provider ครั้งเดียว ก่อนเก็บใช้การตรวจว่าข้อเสนอมาจากรายการฉากที่ส่งจริง ไม่อ้างผลสรุปเมื่อผู้ให้บริการล้มเหลว
- AWS เสียค่าใช้จ่ายตามจริงได้ ควรตั้งงบประมาณ/การเตือนค่าใช้จ่าย

## ติดตั้งบน AWS หลัง merge

ซิงก์ Branch main และ Deploy Lambda เดิมผ่าน CloudShell region Sydney โดยไม่สร้าง DynamoDB เพิ่ม:

```bash
cd ~/AI-ANIMATION && git pull --ff-only origin main && AWS_REGION=ap-southeast-2 AWS_DEFAULT_REGION=ap-southeast-2 bash autodub/deploy.sh https://main.d1wc6w01kiwpnk.amplifyapp.com
```

ต้องรอ Amplify Deploy ผ่านเพื่อเห็นปุ่มใหม่ (AI-ANIMATION) และต้องอัปเดต Lambda เพื่อให้ API `teacher.autoTeach` และ `teacher.autoLessons` ทำงาน มิฉะนั้นเว็บจะแจ้งข้อผิดพลาด โดยไม่กล่าวว่าบันทึกสำเร็จ
