# ซอมบี้บุกโรงเรียนทวีธาภิเศก — แพ็กเกจอนิเมชัน 62 วินาที

**ไฟล์นำเข้า:** `examples/taweetha-zombie-siege.json` (Story Studio JSON เต็มรูปแบบ ไม่ใช่ story-only)
**สำคัญ:** เป็นภาพยนตร์เรื่องแต่ง ไม่ใช่การระบาดหรือเหตุการณ์จริงของโรงเรียนที่มีชื่ออยู่ในเรื่อง

## วิธีใช้งาน
1. เปิด AI-ANIMATION → นำเข้า JSON → **แทนที่โปรเจกต์** → เลือก `examples/taweetha-zombie-siege.json`
2. ตรวจภาพแต่ละฉาก: สถานที่/ตัวละคร/โต๊ะ/ไฟฉาย/หน้าต่าง/ประตู/แสงเตือน ถูกจัดตำแหน่งและมี keyframe ใน `customAssets` ครบแล้ว ไม่ต้องดาวน์โหลด SVG ภายนอก
3. เข้าเครื่องมือ AI พากย์เสียง เลือก `voiceDirection.voiceProfileId` ของแต่ละฉาก (narrator, nont, mind, teacher) แล้วสร้างคลิปเสียงจาก `voiceover` **จริง** เสียงไม่ได้ฝังมาใน JSON
4. ตรวจความยาวเสียงกับภาพ ปรับระยะเวลาหาก TTS พูดไม่ทัน และใช้เครื่องมือ Sound Desk เพิ่มเอฟเฟกต์จากแผน `productionSoundCues` (metadata ไม่ใช่ไฟล์เสียง)
5. พรีวิวก่อนส่งออก ตรวจการเคลื่อนจาก `motionKeys` ความต่อเนื่องตัวละครและซับ จากนั้นเลือกส่งออกในเครื่องหรือบนเซิร์ฟเวอร์ที่เชื่อมไว้

## ข้อตกลงข้อมูล
- โปรเจกต์เต็มประกอบด้วย 6 สถานที่ 4 เสียงตัวละคร 4 รูปแบบตัวละคร rig (นนท์ มายด์ ครูภาคิน ผู้ติดเชื้อ), 12 ฉาก, 62 วินาที
- ใช้ `scene.productionEvents` สำหรับเหตุการณ์/สินทรัพย์ที่ควรมีในฉาก และ `scene.productionPlacements` สำหรับพิกัด x/y 0–100 และ scale 0.12–3; ใน JSON ฝัง `customAssets` ที่พร้อมดูภาพอยู่แล้ว
- `studio-production-assets.js` รู้จักแม่แบบโรงเรียนแบบ SVG ที่มีรูปทรงปลอดภัย (rect, circle, polygon, line); production planner สามารถสร้างสินทรัพย์ซ้ำได้อย่างปลอดภัยหากผู้ใช้ลบ asset ในฉาก
- ตำแหน่งทั้งหมดเป็น **ตำแหน่งศิลป์สมมติ** ไม่ใช่แผนผังจริงหรือคำแนะนำการอพยพของโรงเรียน
- การทดสอบสัญญา: `node tests/taweetha-zombie-smoke.cjs`
- **ไม่มี MP4 หรือเสียง TTS จริงใน GitHub commit นี้**: สร้างผ่านหน้า Studio หรือ pipeline เรนเดอร์ที่เชื่อมต่อก่อนจึงจะได้คลิปพร้อมเสียง
