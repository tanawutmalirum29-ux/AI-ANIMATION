# AI Student Learning Loop — ความจำถาวรและการฝึก CPU

## วิธีใช้งาน
1. นำเข้า JSON เหมือนเดิม เลือกฉากที่มีคำซ้ำหรือบทที่ AI ลูกอาจแก้ผิด
2. ไปที่ AI Production → 6 ผู้ช่วย AI → Script ML เพื่อให้ AI ลูกวิเคราะห์ทุกฉาก และโหลดบทเรียนที่เคยอนุมัติบน AWS ก่อนเสนอแก้
3. ไปที่ AI ครู / API → สอน AI ลูก กด AI ลูกวิเคราะห์ → AI แม่ตรวจ
4. AI แม่ที่เชื่อม API จะเสนอเหตุผลและ label (keep / remove / review) แต่ผู้ใช้ต้องพิจารณาและเลือกคำตอบที่ถูกต้องจริงเอง
5. กดยืนยันบทเรียน ระบบเก็บตัวอย่างที่ผู้ใช้อนุมัติใน AWS DynamoDB เพื่อให้ AI ลูกค้นมาใช้กับฉากในอนาคตได้
6. เมื่อมีอย่างน้อย 60 ตัวอย่างจาก 5 โปรเจกต์และอย่างน้อย 10 ตัวอย่างต่อ label กดฝึกโมเดล CPU
7. ฝึก Naive Bayes จากตัวอย่างจริง ใช้ bigram ภาษาไทย + context tags แบ่ง train/test แยกตามโปรเจกต์
8. ถ้า Holdout Accuracy อย่างน้อย 70% และเหนือ majority baseline จึงสามารถกดอนุมัติเปิดใช้รุ่นใหม่เป็นคำแนะนำเท่านั้น; รุ่นไม่ผ่าน QA ห้ามใช้
9. โมเดลก่อนหน้าเก็บเป็นเวอร์ชันเพื่อเลือกย้อนกลับได้

## ความจำและข้อจำกัด
- ข้อมูลเก็บบน DynamoDB และน้ำหนักของโมเดลที่เปิดใช้ก็เก็บบน AWS ข้อมูลจะยังอยู่หลังเปลี่ยนมือถือหรือรีเว็บ ตราบเท่าที่ฐานข้อมูล/สิทธิ์ยังอยู่
- ระบบดึงตัวอย่างล่าสุด 150 รายการเพื่อใช้อ้างอิง และใช้ล่าสุดไม่เกิน 500 รายการฝึกแต่ละรอบ (รายการเก่ากว่ายังอยู่ในตาราง)
- ไม่ใช่การสร้างจิตสำนึกหรือ Generative AI ผู้เขียนบทเต็มรูปแบบ โมเดลนี้ฝึกสำหรับเจตนาคำซ้ำเท่านั้น; คำแนะนำจากความจำจะป้องกันการลบที่ไม่แน่นอน ไม่แก้บทโดยพลการ
- การอนุมัติยังต้องมาจากผู้ใช้ AI แม่เพียงเสนอ; ไม่ใช้ข้อมูลตอบของ AI แม่เป็นความจริงโดยอัตโนมัติ และต้องตรวจเงื่อนไขผู้ให้บริการ AI ก่อนนำข้อมูลมาเทรน
- การเข้าสู่ระบบเดิมเป็นบัญชี Studio ร่วม ไม่ได้แยกบทเรียนต่อผู้ใช้ การให้รหัสผ่านเว็บแก่คนอื่นเท่ากับอนุญาตให้เข้าถึงข้อมูลฝึก
- ควรเปิด DynamoDB Point-in-Time Recovery/สำรองข้อมูล; การลบตารางหรือบัญชี AWS ทำให้ความจำหายได้; AWS ไม่รับประกันใช้ฟรีตลอด

## ดูบทเรียนที่เก็บไว้บนเว็บ (Memory Dashboard)

เปิด AI-ANIMATION → AI ครู / API → **ประวัติ** ระบบจะโหลดจาก DynamoDB และแสดง:
- บทเรียนที่คุณอนุมัติ แยก **ควรเก็บ / ควรลบ / ต้องตรวจ** พร้อมต้นฉบับและวันบันทึก
- ค้นหาคำในบท เหตุผล AI ครู เหตุผลผู้ใช้ หรือ Scene ID โดยค้นเฉพาะรายการที่โหลดแล้ว
- แตะรายการเพื่อขยายดูเหตุผล บริบท ชื่อตอน/ฉาก และการตัดสินใจเดิมของ AI ลูก
- กด **โหลดบทเรียนหน้าถัดไปจาก AWS** เพื่อดูต่อทีละ 40 รายการ ไม่สแกนทั้งตารางหรือส่งข้อมูลทั้งหมดมาในครั้งเดียว
- ประวัติ **10 รุ่นโมเดลล่าสุด** พร้อม Accuracy, Train/Test count, QA status และรุ่นที่เปิดใช้งาน
- **ประวัติ Feedback จาก AI ครู** แยกต่างหากสำหรับโปรเจกต์ปัจจุบัน; เป็นข้อมูลคนละชนิดกับบทเรียนที่ใช้ฝึก AI ลูก

การค้นหาบนหน้าจอยังไม่ใช่การค้นหาทั้ง DynamoDB โดยอัตโนมัติ ข้อมูลทั้งหมดจะปรากฏได้ด้วยการกดโหลดหน้าถัดไปเรื่อย ๆ ซึ่งทำให้การใช้งานบนมือถือประหยัดการเรียก AWS มากกว่า

ไม่ต้องใส่ API Key ใหม่เพื่ออ่านประวัติที่เก็บใน AWS แต่ต้องล็อกอิน Studio และติดตั้ง Lambda รุ่นใหม่ให้รองรับ cursor ก่อน ใช้ IAM อ่านแบบ Query ตาม Partition Key เดิม ไม่มีสิทธิ์แก้/ลบข้อมูลจากหน้านี้

หลัง PR merge ต้องรันใน CloudShell ของ AWS region ap-southeast-2:

    cd ~/AI-ANIMATION && git pull --ff-only origin main && AWS_REGION=ap-southeast-2 AWS_DEFAULT_REGION=ap-southeast-2 bash autodub/deploy.sh https://main.d1wc6w01kiwpnk.amplifyapp.com
