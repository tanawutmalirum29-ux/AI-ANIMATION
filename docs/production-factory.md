# Production Factory — ปุ่มเดียว 6 ผู้ช่วย (รุ่นเริ่มต้น)

เปิด **AI → 6 ผู้ช่วย AI → เริ่มผลิตทั้งโปรเจกต์ · 6 ผู้ช่วย** หลังนำเข้าไฟล์ JSON เรื่องจาก AI ภายนอก

## ออกแบบให้ผู้ช่วยส่งต่องานได้โดยไม่ต้องสื่อสารด้วยข้อความ

- ผู้ช่วย 01 **จัดองค์ประกอบ** ตรวจตำแหน่งตัวละครที่ซ้อนกันโดยไม่ได้กำหนดเจตนา; ไม่เขียนบทหรือแก้ตำแหน่งที่ถูกล็อกไว้
- ผู้ช่วย 02 **SVG** ใช้แม่แบบรูปทรงที่ตัวเรนเดอร์รองรับ สร้างสะพานไม้ กล่องเครื่องมือ เครื่องสะท้อนแสง สายพาน แสงสามวาบ และน้ำไหลบ่า เมื่อพบเหตุการณ์ตรงกับบทและยังไม่มี asset จากระบบ
- ผู้ช่วย 03 **แอนิเมชัน** สร้าง keyframe การกระโดดที่ขาดอยู่ และเคลื่อนไหว SVG ตามเวลาฉากจริง รองรับตัวอย่างสะพานยุบ กล่องตก แสงวาบ
- ผู้ช่วย 04 **พากย์** ใช้ระบบ Auto Dub เดิม และไม่สร้างคลิปซ้ำเมื่อโปรเจกต์มีเสียงครบ; ต้องมีบริการ TTS เชื่อมต่อหากไม่มีเสียง
- ผู้ช่วย 05 **เวลา/ตัดต่อ** ทำหลังเสียงจริงครบ ใช้การวัดเสียงและระบบแบ่งตอนเดิม ห้ามตัดเสียงค้างหรือยืดความเงียบเพื่อบังคับให้ครบ 60 วินาที
- ผู้ช่วย 06 **QA** ตรวจความครบของเสียง โครงเรื่อง JSON รูปทรง SVG และจุดเสี่ยงภาพ แจ้งขั้นตอนที่ต้องให้คนตรวจ แทนการอ้างว่างานเรนเดอร์ถูกต้องทุกเฟรม

ตัววางแผนภาพจาก JSON และระบบเสียงทำงานได้ในช่วงเดียวกัน แต่ **ไม่แก้โปรเจกต์พร้อมกัน**: รอให้เสียงสร้างเสร็จก่อน ตรวจแผนภาพแบบ dry-run, สำรองข้อมูล, แล้วจึงใช้การแก้ไขที่ผ่าน QA เพื่อป้องกัน race condition

## ความสามารถที่ตั้งใจจำกัด

- ทั้งหกบทบาทเป็น **เวิร์กโฟลว์เฉพาะทางที่ใช้กฎ (deterministic agents)** ไม่ใช่โมเดลภาษาที่ฝึกใหม่ 6 ตัว ยังไม่มี Fine-tuning
- รองรับงานทั่วไปและเหตุการณ์ที่มีแม่แบบ SVG แล้วเท่านั้น รายละเอียดเรื่อง/ตัวละครแปลกใหม่อาจยังต้องให้มนุษย์หรือโมเดลภายนอกกำกับ
- ภาพ 2D SVG มีการขยับแบบ translate, rotate, scale, opacity ด้วย keyframe แต่ **ไม่ใช่ physics simulation** หรือระบบแก้ skeletal rig อย่างชาญฉลาด
- ไม่แปลง imagePrompt ที่เป็นข้อความให้กลายเป็น 3D หรือวัตถุอิสระได้โดยอัตโนมัติ
- ถ้าไม่มีไฟล์เสียงและบริการ TTS ไม่พร้อม ผู้ช่วยภาพที่ทำได้จะยังทำต่อ ส่วนจัดเวลาจะหยุดอย่างปลอดภัยและแสดง **ต้องตรวจเพิ่มเติม**
- ไม่ลบเนื้อเรื่อง ตัดคลิป/เหตุการณ์ที่ตั้งเวลาชัด หรือแก้ฉากที่ล็อกไว้ (`autoDirectorLocked`, `manualLock`, `[LOCK_VISUAL]`)
- การกดซ้ำตรวจป้าย `autoDirectorTag` และ `motionKeys` เพื่อไม่สร้างซ้ำ
- งานแสดง **เสร็จ** หมายถึงผ่าน QA เชิงข้อมูล; ต้องชมวิดีโอที่ส่งออกจริงเพื่อตรวจ layering, ร่างกาย, เสียง และจังหวะ

## วิธีทดสอบ

```bash
node tests/production-six-specialists.test.cjs
node tests/production-factory-browser-smoke.cjs
```

การทดสอบตัวที่สองใช้ Chromium ผ่าน Playwright ซึ่งติดตั้งใน GitHub Actions

## ขั้นถัดไป

เพิ่ม asset ที่ผ่านการตรวจสอบจากผู้ใช้ เพิ่ม motion/skeleton rig ที่ตรวจการซ้อนทับได้จริง และใช้ข้อมูล JSON + วิดีโอก่อน/หลังที่ได้รับอนุมัติสำหรับการประเมินโมเดลภาพในอนาคต ก่อนจะขยายไปสู่ AI ที่สร้าง SVG แบบอิสระ
