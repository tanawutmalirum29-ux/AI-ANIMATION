# โหมดเนื้อเรื่องล้วน (Story-only JSON)

โหมดนี้มีไว้สำหรับ **สร้าง เขียน ตรวจ แก้ไข และสอน AI ลูกจากบทภาษาไทย** ไม่ต้องสร้างภาพ ไม่ต้องใส่ `imagePrompt`, `rig`, `camera`, `actors`, `lighting`, เสียง หรือวิดีโอ ในไฟล์ JSON ต้นฉบับ

## ตัวอย่างสั้นที่สุด

```json
{
  "type": "story-only",
  "title": "คืนฝนตก",
  "story": "ฝนตกหนักตลอดคืน ชาวบ้านเริ่มเก็บของขึ้นที่สูง\n\nเมื่อรุ่งเช้ามาถึง ทุกคนออกมาตรวจระดับน้ำในคลอง"
}
```

รองรับรูปแบบเพิ่ม:
- `chapters:[{title,text}]` หรือ `chapters:[{title,paragraphs:["...","..."]}]`
- `episodes:[{title,text}]` หรือ `episodes:[{id,title,scenes:[{id,text}]}]`
- `episodes[].scenes[].voiceover` สำหรับงานที่มีบทพากย์อยู่แล้วโดยยังไม่มีภาพ
- `paragraphs:["..."]` หรือ `story:"..."` ทั้งเรื่อง
- รองรับ JSON นำเข้าผ่าน **เมนูนำเข้าเดิม** (เลือกไฟล์ .json หรือวาง JSON) และแท็บ **AI → เนื้อเรื่องล้วน** โดยเฉพาะ

> หากเนื้อหายาว ระบบจะแยกเป็นฉากสำหรับการตรวจบท โดยเก็บลำดับข้อความต้นฉบับไว้; ขนาดปัจจุบันจำกัด 200,000 ตัวอักษรต่อไฟล์, 80 ตอน, 400 ฉาก และประมาณ 1,100 ตัวอักษรต่อฉากเพื่อให้ AI แม่ตรวจเป็นชุดได้ ไม่ตัดเนื้อเรื่องทิ้งเงียบ ๆ เมื่อเกินขีดจำกัด

## วิธีใช้งานสำหรับโฟกัสการฝึกบท

1. เปิด AI-ANIMATION → **AI Production → เนื้อเรื่องล้วน**
2. เลือกไฟล์ .json จากเครื่องหรือวาง JSON เนื้อเรื่องล้วน และกดนำเข้า
3. เลือกฉาก เขียน/แก้บทในช่องข้อความ และกด **บันทึกบทฉาก** (Undo ย้อนกลับได้)
4. กด **AI ลูกตรวจทั้ง JSON** ซึ่งใช้การวิเคราะห์และโมเดล CPU ในเว็บได้โดยไม่ต้องเรียก API ภายนอก
5. กด **AI แม่สอนและบันทึก AWS** หรือเปิด **AI ครู / API** แล้วกดปุ่มลัด **สอน AI ลูก** ระบบจะตรวจบทและบันทึกบทเรียนที่ AI แม่เสนอไว้ใน DynamoDB หากเชื่อม API/เข้าสู่ Studio สำเร็จ
6. กด **ส่งออก JSON เฉพาะเนื้อเรื่อง** เพื่อได้ไฟล์เล็ก ๆ กลับไปแก้หรือให้ AI ภายนอกเขียนต่อโดยไม่ติดรูป ภาพเคลื่อนไหว กล้อง หรือเสียง

ทั้งสองโหมดใช้ระบบตรวจบทที่อ้างอิง `episodes[].scenes[].voiceover` ร่วมกัน แต่การทำงานในแท็บนี้ **ไม่ได้สร้างภาพหรือเรนเดอร์วิดีโอ** ซึ่งหมายความว่าโปรเจกต์ที่นำเข้าบทล้วนยังไม่พร้อมส่งออกวิดีโอโดยไม่เพิ่มสื่อภายหลัง

## ทำไมโปรเจกต์ภายในยังมี schema ฉาก

ตัวแปลง `studio-story-only.js` แปลงบทอย่างเดียวเป็นรูปแบบฉากขั้นต่ำสำหรับให้ Script ML, Story Continuity Coach และ AWS Teacher ใช้ระบบเดิมได้ โดยเพิ่มค่า default ที่เครื่องมือจำเป็นต้องใช้ภายใน ไม่สร้างไฟล์ภาพหรือเรียกสร้างวิดีโอ การส่งออก `type:"story-only"` จะส่งเฉพาะตอน/ฉากและข้อความต้นฉบับกับ notes อีกครั้ง

**โปรเจกต์อนิเมชันเต็มที่มีฟิลด์ภาพและกล้องจะไม่ถูกแปลงหรือทิ้งรายละเอียด** หากใช้เมนูนำเข้าแบบเดิม ตัวตรวจจะใช้โครงสร้างเดิมเหมือนก่อนหน้า

## สถานะความจำและโมเดล

การสอนอัตโนมัติบันทึกเป็น `teacher-auto-unverified` แยกจากข้อมูลที่มนุษย์อนุมัติ ไม่ฝึกน้ำหนัก Generative AI ใหม่โดยอัตโนมัติ ข้อมูลบทเรียนที่บันทึกใน AWS ใช้เป็นตัวอย่างอ้างอิงในการตรวจครั้งถัดไป ส่วนโหมด CPU ฝึกจากชุดข้อมูลสังเคราะห์ตามที่มีในโปรเจกต์
