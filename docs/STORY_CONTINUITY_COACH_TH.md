# AI Story Continuity Coach — ฝึกเรื่องต่อเติมและเรียบเรียงเนื้อหา

เพิ่มความสามารถต่อไปนี้ให้ AI-ANIMATION โดยยังรักษาเนื้อเรื่องต้นฉบับที่นำเข้าจาก JSON

## ใช้งาน
1. นำเข้าเรื่อง JSON ตามปกติ แล้วเลือกฉากที่มีบทพากย์
2. เปิด **AI ครู / API → ต่อเติมบท** กด **AI ลูกตรวจบริบท** หน้าจอแสดงบทฉากก่อนหน้า/ปัจจุบัน/ถัดไปและข้อสังเกตที่ตรวจได้จากโครงสร้าง
3. กด **AI แม่เสนอแก้** เพื่อให้ LLM ภายนอกอ่าน 3 ฉาก พร้อมตัวอย่างบทแก้ที่คุณอนุมัติไว้สูงสุด 3 รายการ (เลือกจากความใกล้เคียงของคำ ไม่ส่งทั้งโปรเจกต์) แล้วเสนอแก้บทภาษาไทยและอธิบายเหตุผล
4. แก้ข้อความที่เสนอด้วยตัวเองได้ เลือกประเภท `continuity`, `clarity`, `expand`, `pacing`, `keep` และใส่เหตุผล
5. กด **อนุมัติและเก็บเป็นบทเรียน** ระบบบันทึกคู่ **บทเดิม / บทที่แก้ / ฉากข้างเคียง / เหตุผล** ลง AWS DynamoDB (แยกชุดกับความจำคำซ้ำ) หลังคุณยืนยันเท่านั้น
6. หากต้องการแก้โปรเจกต์จริง กด **ใช้บทที่แก้ในฉาก** ระบบ dry-run ตรวจ JSON, ดาวน์โหลดสำรอง, ตรวจว่าฉากไม่ถูกแก้ระหว่างทาง และทำให้เสียงพากย์เดิมใช้ไม่ได้ พร้อมแจ้งให้สร้างซับ/เสียงใหม่

## ข้อจำกัดและแนวทางการเรียนรู้

AI ลูกในโหมดนี้ยังไม่ใช่ Generative LLM ฝึกน้ำหนักด้วยบทของคุณ ระบบเช็กรูปแบบที่สังเกตได้และค้นตัวอย่างที่ผู้ใช้อนุมัติมาให้ AI แม่ประเมินใหม่ (retrieval/few-shot) จึง **ปรับการเสนอแก้จากตัวอย่างของคุณได้โดยไม่ต้องฝึกน้ำหนัก** แต่ผลไม่เท่ากับโมเดลเข้าใจนิยายด้วยตัวเอง

เมื่อข้อมูลจริงมากพอ จึงสามารถส่งออกเป็นชุดข้อมูลสำหรับ fine-tuning โมเดลภาษาที่ได้รับอนุญาต โดยแยกเรื่องเพื่อประเมินก่อน/หลังฝึก ต้องใช้ compute และตรวจเงื่อนไขการนำ output ของผู้ให้บริการไปฝึก อย่าถือว่าเพียงกดบันทึกเท่ากับฝึกน้ำหนักแล้ว

AI แม่อาจอธิบายผิดหรือแต่งเหตุการณ์ใหม่ได้ ดังนั้นห้ามอนุมัติงานโดยไม่ได้อ่าน และระบบจะไม่เปลี่ยนบทอัตโนมัติจากข้อเสนอของ AI แม่

## ความจำ
- จัดเก็บในตาราง DynamoDB เดิม `story-studio-teacher-feedback` Partition Key `learning#story-coherence`
- ดึงล่าสุด 60 ตัวอย่างในการตรวจหนึ่งรอบ; ส่งให้ LLM สูงสุด 3 ตัวอย่างที่มีเนื้อหาใกล้เคียงกัน เพื่อลดโควตา
- การบันทึกสำเร็จคงอยู่บน AWS ตราบเท่าที่ยังมีตารางและข้อมูล ไม่รับประกันว่าจะไม่สูญหายหากถูกลบ
- ข้อมูลของทุกโปรเจกต์ใน Studio ที่ใช้การล็อกอินเดียวกันยังแชร์พื้นที่การอ่านบทเรียน ต้องจำกัดผู้เข้าถึง
- ใช้ AWS IAM/DynamoDB PutItem + Query เดิม ไม่สร้างทรัพยากรใหม่
- พฤติกรรมหน้าเดิม เช่น JSON import, Preview, Cloud Export ยังอยู่เหมือนเดิม

## Deploy
หลัง PR merge เข้า main และ GitHub Actions ผ่านครบ ให้ AWS CloudShell ใน Sydney ใช้คำสั่ง:

```bash
cd ~/AI-ANIMATION && git pull --ff-only origin main && AWS_REGION=ap-southeast-2 AWS_DEFAULT_REGION=ap-southeast-2 bash autodub/deploy.sh https://main.d1wc6w01kiwpnk.amplifyapp.com
```

ต้องอัปเดต Lambda เพราะเพิ่ม student.storyLesson/student.storyLessons ในโมดูลเดิม ไม่ต้องเรียก setup-teacher.sh อีก แต่การเรียก AI ภายนอกและ AWS อาจมีค่าใช้จ่ายตามใช้งาน
