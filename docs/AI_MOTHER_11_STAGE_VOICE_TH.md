# AI แม่ 11 ขั้น + พากย์แยก (รุ่นทดลอง)

## สิ่งที่เพิ่ม

- หน้า **AI Production** มีสายการผลิต 11 ขั้นสำหรับบท/ภาพ/การเคลื่อนไหว/เวลา/QA โดย **ไม่พากย์อัตโนมัติ** ระหว่างงาน 11 ขั้น
- เลือก **ระบบเดิม 11 ขั้น** หรือ **ระบบเดิม + AI แม่** แล้วโหลดรายชื่อโมเดลที่แอดมินเชื่อมอยู่ใน AWS
- ระบบแบ่งฉากเป็นชุดละไม่เกิน 3 ฉาก กระจายให้คีย์ AI แม่ที่พร้อมใช้งานมากสุด 6 ตัวพร้อมกัน (แต่ละคีย์ทำงานตามคิวของตัวเอง) หากตัวหนึ่งล้มเหลวจะลองสำรองอีกตัวหนึ่งหนึ่งครั้ง
- เลือกเฉพาะฉาก/ตอน/ทั้งโปรเจกต์สำหรับการตรวจของ AI แม่ พร้อมคำสั่งเสริมและปุ่มสั่งเฉพาะหนึ่งใน 11 ขั้น
- ข้อเสนอจาก AI แม่ต้องผ่านตัวตรวจ JSON ของ StudioAPI ก่อนบันทึก โดยค่าเริ่มต้นแก้ **หมายเหตุการจัดฉาก** และ **เวลาเฉพาะฉากที่ไม่มีคลิปเสียงจริง** ในขอบเขตจำกัดเท่านั้น ไม่เปลี่ยนบทบรรยาย ตัวละคร SVG/rig กล้อง Keyframe คลิปเสียง หรือสื่อที่ล็อกไว้โดยตรง
- งานภาพจากแม่แบบ/เครื่องมือที่มีอยู่ยังคงทำงานตามเดิม การได้คำแนะนำจาก AI แม่ **ไม่เท่ากับ** มี worker สร้าง SVG, Rig, Animations หรือคุณภาพระดับพิกเซลได้เองครบทุกตำแหน่ง

## พากย์เสียง (แยกออกจาก 11 ขั้น)

เลือก **ระบบ · Edge TTS** หรือ **AI แม่ · Gemini TTS** และกำหนด AI แม่ที่ต้องการ โดยทางเลือก AI แม่จะใช้ Native TTS จริง ไม่ใช่เอาข้อความของโมเดลไปพากย์ผ่าน Edge TTS แล้วเรียกว่าเสียง AI แม่

- AI แม่ที่เลือกต้องเป็นคีย์ Gemini ที่พร้อมใช้งาน และบัญชีต้องมีสิทธิ์ใช้ `gemini-2.5-flash-preview-tts` (โมเดล/โควตาเปลี่ยนตามผู้ให้บริการ)
- OpenRouter และ OpenAI-compatible ที่ตั้งค่าเป็น text-only ไม่สามารถสร้างไฟล์เสียงผ่านปุ่ม AI แม่ได้ จะแจ้งข้อจำกัดแทนการสลับกลับไประบบเดิมโดยไม่บอก
- ไฟล์ Gemini PCM จะถูกแปลงเป็น WAV ก่อนนำเข้าไปยัง Sound Desk เดิม จึงยังใช้การจัดจังหวะตามความยาวเสียงจริง และไม่พากย์ทับคลิปเดิมที่ใช้งานได้
- API TTS อาจมีค่าใช้จ่ายหรือโควตาตามบัญชีโมเดล; ระบบไม่ได้เพิ่ม API Key/สมัครบริการเอง

## การติดตั้งและความปลอดภัย

1. ต้องมี GitHub OAuth admin และ `StoryStudioAccess` ใช้งานได้
2. แก้โค้ดหน้าเว็บเพียงอย่างเดียวไม่พอ: ต้อง deploy Lambda ใหม่เพื่อรวม `autodub/teacher_production.py` ผ่าน GitHub Actions หรือ `autodub/deploy.sh`
3. โมดูลพิเศษทั้งหมดตรวจ role/admin จากเซิร์ฟเวอร์; ไม่เคลื่อนคีย์หรือความลับลง localStorage/JSON
4. สำรองโปรเจกต์ก่อนใช้ผล AI แม่ปรับฉาก; ตรวจคลิปส่งออกจริงก่อนเผยแพร่
5. เริ่มทดสอบด้วยโปรเจกต์สั้น และกด **พากย์เฉพาะที่ยังไม่มีเสียง** แยกออกมาต่างหากหากต้องการเสียง

## ข้อจำกัด

- งาน AI แม่เป็นข้อเสนอจากโมเดลที่เชื่อม ไม่ใช่ระบบฝึกน้ำหนักโมเดล AI ลูกใหม่
- การประมวลผลหลายฉากพร้อมกันขึ้นกับโควตาและความเร็ว API; เมื่อเจอ 429/timeout ระบบแสดงคำเตือน ไม่อ้างว่างานสำเร็จ
- งานยังทำในหน้าเว็บระหว่างเปิดหน้า; ยังไม่มี Step Functions checkpoint สำหรับการมอบหมายงาน 11 ขั้นในฟีเจอร์นี้
- โหมด 11 ขั้นจะระบุปัญหาเสียงที่ขาด แต่ไม่เติมเสียงให้เอง; ให้เลือกพากย์หลังจบ
- ฝั่งสมาชิกยังใช้โมเดล AI ลูกและเครื่องมือ CPU เดิม ไม่ได้รับคีย์ AI แม่ของแอดมิน
