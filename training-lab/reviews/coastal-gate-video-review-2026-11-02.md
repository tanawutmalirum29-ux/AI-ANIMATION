# ตรวจผลจริง: ประตูน้ำก่อนตลาดท่วม — Export 2 พ.ย. 2026

**สถานะ:** หลักฐานสำหรับ QA / รีวิวโดย AI **รอผู้ใช้ตรวจรับ**; **ห้ามนำเข้า approved training datasets หรืออ้างว่า fine-tune แล้ว**

หลักฐาน: คลิปที่ผู้ใช้อัปโหลด `ฝึก-AI-ประตูน้ำก่อนตลาดท่วม-1.mp4` (ไม่เก็บวิดีโอไว้ใน GitHub สาธารณะ) + ตัวอย่าง JSON `examples/coastal-gate-ml-training-one-episode.json` ตรวจเฟรมจริงช่วงห่าง 0.75 วินาทีและตรวจเสียงด้วย RMS; ไม่ได้ทำ speech-to-text จึงไม่ยืนยันว่าอ่านครบหรือออกเสียงถูกทุกคำ

## ตัวเลขที่ตรวจได้

- Export ยาว **20.2417 วินาที**, 512×910 พิกเซล ≈ 9:16, ภาพประมาณ 29.94 fps, AAC 48 kHz สองช่องที่สัญญาณแทบตรงกัน
- เสียงพูดปรากฏโดยคร่าวที่ `0.20–4.75`, `5.80–9.85`, `10.90–14.60`, `15.65–19.30` วินาที
- ช่องว่างไม่มีสัญญาณจริงที่รอยต่อประมาณ **1.05 วินาที × 3** และอีก 0.90 วินาทีท้ายวิดีโอ — ชัดเจนสำหรับภาพฝนตกซึ่งควรมีบรรยากาศต่อเนื่อง
- การตัดจากโครงเดิม 35 วินาทีลงเหลือ ~20.24 วินาที **ไม่ใช่ข้อผิดพลาดในตัวเอง** หากยึดความยาวเสียงพากย์จริง; ห้ามเติมฉากค้างเงียบเพื่อให้ครบ 60 วินาที
- ซับในไฟล์ส่งออกอยู่ในกรอบภาพ/กึ่งกลางตามตัวอย่างที่ตรวจ ไม่พบการล้นขอบขวา แต่การแบ่งวลีบางจุดยังไม่ดี; ปัญหา UI พรีวิว iPad เป็นคนละประเด็น

## มอบหมายให้ทีม AI ภายใน

- **AI-1 Composition:** เลือกช็อตที่ชี้เหตุการณ์ได้; ท่าตัวละครกับเลย์เอาต์บังคับให้เห็นคนขายของตอนถูกเตือน; กำหนดระยะใกล้–ไกลและฉากเนินสูง
- **AI-2 SVG:** เปลี่ยนรูปทรงประตูรั้ว/อาคารเป็นประตูระบายน้ำที่อ่านออกทันที มีไฮดรอลิก/รางน้ำ แก้ geometry ท้องฟ้าลอย และ flood occlusion
- **AI-3 Motion:** น้ำยกตามเวลา, รั่ว/กระเซ็น, การวิ่งและมือชี้, คนขายตอบสนอง/ยกของ, น้ำท่วมพื้นที่ต่ำจริง ไม่เพิ่มคีย์เฟรมแบบเดาที่ทำให้ตัวละครหลุดพื้น
- **AI-4 Voice/Sound:** ตรวจว่าพูดครบจากเสียงจริง, มิกซ์ฝน/ตลาด/น้ำไหลต่อเนื่อง, ลบ dead-air คงที่ที่รอยต่อ ถ้าไม่ใช่ pause ที่ตั้งใจ
- **AI-5 Timing/Subtitles:** เก็บความยาวตามเสียง ~20 วินาทีได้, เปลี่ยนช็อตให้สัมพันธ์การออกเสียง, ตัดซับตามวลีไม่แยกคำเชื่อม
- **AI-6 QA:** ตรวจ MP4 จริง (ภาพ/เสียง/ซับ) และเปรียบเทียบกับเกณฑ์ก่อนอนุมัติ; metadata ใน JSON ไม่พิสูจน์เฟรมจริง

## Story-to-Action ground truth *สำหรับการตรวจรับ ไม่ใช่ตัวอย่างฝึก approved*

1. `train-s01`: sea level rising visibly + harbor/market establishing shot.
2. `train-s02`: gate is obviously a floodgate; low-edge leak is visible and time-varying; character finds leak.
3. `train-s03`: Pim runs to stall, warns another visible person, vendor moves goods.
4. `train-s04`: lowland flooded; market is empty **because** people moved away; cut/reveal people on safe high ground.

**เงื่อนไขผ่าน:** คนดูเข้าใจ `เหตุการณ์ → การกระทำ → ผลลัพธ์` จากภาพ แม้ปิดเสียงชั่วคราว; ตรวจซับกับคำจริงแยก; ช่องรอยต่อเสียงเหมาะสม; ช็อตชัดเจน; ไม่อ้างว่าสมบูรณ์จากเพียงการมี `worldEffects` ใน JSON

## ใช้เพื่อฝึก Machine Learning เมื่อใด

กรณีนี้มี **หนึ่งคลิปที่มีข้อผิดพลาด** จึงเหมาะเป็น *ชุดประเมิน/negative example* แต่ไม่เพียงพอสำหรับฝึกโมเดลใหม่ และไม่ควรนำไปปะปนใน `training-lab/datasets/approved/layout-spacing.jsonl` เพราะโจทย์หลักคือ Story-to-Action, SVG และเสียง ไม่ใช่การจัดระยะห่างตัวละครเท่านั้น

หลังแก้ให้เรนเดอร์เรื่องเดิมอีกครั้ง จับคู่เฟรมก่อน/หลังและลำดับเหตุการณ์ให้ผู้ใช้อนุมัติ แล้วรวบรวมจาก **หลายเรื่อง/หลายสถานที่** แยกชุดทดสอบตามเรื่องก่อนฝึกโมเดล ranking ของช็อตหรือ motion; อย่าใช้คะแนนจากเรื่องเดียวรับรองการผลิตทั้งระบบ
