# One-click six-stage Story Studio production

## สถานะความสามารถจริง

หกขั้นนี้เป็นตัวช่วยผลิตที่ทำงานต่อกันในเบราว์เซอร์โดยใช้ JSON กลางเดียวกัน **ยังไม่ใช่โมเดล AI ที่ฝึกน้ำหนักหกตัว** และไม่ได้คุยกับ LLM ภายนอกระหว่างขั้น ขณะนี้รองรับงานที่มีกฎหรือแม่แบบอยู่แล้วก่อน จากนั้นจึงขยายไปยัง AI inference จริงเมื่อมี provider/API และชุดทดสอบเพียงพอ

## สัญญาร่วมระหว่างขั้น

ทุกขั้นอ่าน `StoryStudioBridge.get()` และไม่ลบข้อความ `voiceover` ของ AI ผู้เขียนเรื่องนอกเว็บ ข้อแก้ไขที่เป็นโครงสร้างผ่าน `StudioAPI.apply(ops,{dryRun:true})` และ `StudioAPI.apply(ops)` พร้อมบันทึกสำรอง IndexedDB ก่อนแก้ เมื่อคำสั่งไม่ผ่าน Schema Validation ห้ามพยายามใช้คำสั่งนั้นโดย force

| ขั้น | สิ่งที่ทำได้ในรุ่นนี้ | สิ่งที่ยังทำไม่ได้ |
|---|---|---|
| AI-1 Layout | แยก actor ที่ทับกันและไม่มี motion/anchor/interaction/latch ที่ผู้เขียนกำหนด | เข้าใจเจตนาการแสดงทุกท่าทาง |
| AI-2 SVG | สร้างภาพร่าง SVG ที่ปลอดภัยจากแม่แบบ 6 เหตุการณ์ เช่น กล่องตก สะพานถล่ม | วาด asset/character ซับซ้อนหรือสร้างชิ้นส่วนใหม่แบบอิสระ |
| AI-3 Motion | เติมตำแหน่งเดิน/วิ่งให้ actor ที่ pose=walk/run แต่ไม่มี motion; รันคีย์เฟรม SVG ที่มาจาก AI-2 | แก้ข้อศอก ข้อนิ้ว และ Rig ซับซ้อนอัตโนมัติ |
| AI-4 Voice | จัดซับเมื่อยังไม่มี แล้วพากย์เสียงที่ยังขาดผ่าน Edge TTS; มีเสียงครบจะข้าม | เรียก TTS โดยไม่มี gateway หรือประกันว่าสังเคราะห์ทุกคำครบจากคลิปอย่างเดียว |
| AI-5 Timing | ปรับเวลาตามไฟล์เสียงจริง แบ่งตอนตามรอยต่อปลอดภัย; รักษา timed SVG/actor keyframes | ยืดเนื้อเรื่องหรือเสียงปลอมเพื่อให้ครบ 60 วินาที |
| AI-6 QA | ตรวจ JSON + risk จากการตั้งค่าเหตุการณ์/ภาพ/ตำแหน่ง | ตรวจ pixels ทุกเฟรมหรือยืนยันว่าเหตุการณ์ใน video สมจริง |

## รูปแบบผลลัพธ์

ในแท็บ AI มีปุ่ม **เริ่มผลิตด้วย 6 ผู้ช่วย · ปุ่มเดียว** และสถานะ `รอทำงาน / กำลังทำ / เสร็จ / ข้าม / มีข้อจำกัด / ล้มเหลว` ต่อขั้น โปรเจกต์และสถานะบันทึกในเครื่อง เมื่อเน็ตขาด/รีโหลดให้กดรันซ้ำได้; แม่แบบ SVG ตรวจชื่อซ้ำก่อนเพิ่ม และเสียงพากย์จะข้ามเมื่อมีคลิปอยู่แล้ว

หากบริการเสียงไม่พร้อม ระบบเดินขั้นถัดไปที่ปลอดภัยและแจ้งคำเตือน ไม่รายงานว่าเสียงครบโดยไม่มีหลักฐาน เมื่อมี warning หรือผล export ยังไม่ผ่านคนตรวจ ให้ถือเป็น **needs_attention** ไม่ใช่ production-ready

## สัญญา SVG

`scene.customAssets[]` แต่ละ item ต้องมี `asset` รูปแบบที่ `StoryAssetCore.asset` ตรวจแล้วเท่านั้น ใช้ 1–60 รูปทรงจาก rect/circle/ellipse/line/polygon (ไม่มี HTML/JS หรือ URL) รวมได้ไม่เกิน 40 SVG ต่อฉาก `motionKeys` เป็น array ของ `{t,x?,y?,scale?,rotate?,opacity?}` โดยเวลาคือวินาทีภายในฉาก ระดับที่รองรับ: `x/y 0..100`, `scale .12..3`, `rotate -180..180`, `opacity 0..1`. Renderer แบบเดียวกันใช้ทั้ง preview กับ MP4 export และ auditor ถือว่าคีย์เฟรมที่มีเวลามากกว่า 0 เป็นเหตุการณ์ที่ต้องรักษา

## ขอบเขตการเทรนในอนาคต

เก็บ **JSON ต้นฉบับ + วิดีโอผลลัพธ์ + ข้อผิดพลาดที่วัด + ตัวอย่างแก้ที่ผู้ใช้ออกความเห็นแล้ว** ลงใน Training Lab โดยไม่เอาวิดีโอที่แก้ยังไม่ถูกต้องไปประกาศเป็น label ที่ผ่าน QA เมื่อจะติดตั้งโมเดล AI จริง ให้เริ่มจากผู้ช่วยวางองค์ประกอบและแก้ภาพ SVG แบบ constrained output พร้อม regression ทดสอบอย่างน้อยหลายเรื่องและสถานการณ์หลากหลายก่อน
