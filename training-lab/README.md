# AI Training Lab — ระยะเตรียมข้อมูล

สถานะ: **Data intake + measured evaluation + deterministic timing correction** (ยังไม่มีการฝึกน้ำหนักโมเดลจริง)

## หลักการ
ผู้ใช้รับผิดชอบเลือก/อนุมัติเนื้อเรื่องจาก AI ภายนอก ผู้ช่วยใน Story Studio รับผิดชอบจังหวะภาพ เสียง การแบ่งตอน และ QA โดยไม่เปลี่ยนเนื้อเรื่องตามอำเภอใจ

## วิธีใช้งาน
1. คัดลอก [STORY_AUTHOR_PROMPT_TH.md](./STORY_AUTHOR_PROMPT_TH.md) ส่งให้ AI ภายนอก
2. นำ JSON ที่ได้รับมาตรวจ syntax และนำเข้า Story Studio
3. เก็บต้นฉบับที่อนุมัติไว้ใน `training-lab/datasets/approved/` (สร้างโฟลเดอร์เมื่อมีข้อมูลจริง)
4. เก็บกรณีทดสอบแยกจากผลงานจริงใน `training-lab/datasets/fixtures/`
5. บันทึกผลตรวจที่อิงหลักฐาน เช่น ความยาวเสียงจริง จุดตัดฉาก และข้อผิดพลาด ไม่ใช้คะแนนที่ AI แต่งเอง
6. แบ่งชุดข้อมูลตาม **เรื่อง** เป็น train / validation / test ก่อนฝึก เพื่อป้องกันฉากจากเรื่องเดียวกันรั่วข้ามชุด

## สิ่งที่จะวัด
- ความถูกต้องของ JSON และการอ้างอิง ID
- เสียงพากย์ครบ ไม่มีการตัดหรือทิ้งเนื้อหา
- สัดส่วนตอนที่มีความยาว 60–65 วินาทีเมื่อแบ่งได้อย่างปลอดภัย
- เวลาภาพค้างหลังเสียงจบ และความคลาดเคลื่อนของซับ
- ความต่อเนื่องของตัวละคร/ตำแหน่ง/เหตุการณ์ (ต้องมี QA เชิงภาพเพิ่มเติม)
- จำนวนครั้งที่ผู้ใช้ต้องแก้เอง เทียบ baseline

## ข้อจำกัด
ข้อมูลสังเคราะห์ไม่ยืนยันความสามารถในงานจริง โมเดลขนาดเล็กไม่สามารถเข้าใจเนื้อเรื่องเชิงลึกโดยอัตโนมัติ การเพิ่มความสามารถต้องผ่านการทดสอบกับข้อมูลที่ไม่ใช้ฝึกและได้รับการอนุมัติ การติดตั้งโมเดลต้องมี rollback และไม่กระทบ production ระหว่างทดลอง
