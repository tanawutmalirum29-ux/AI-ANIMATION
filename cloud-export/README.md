# Cloud Export บน AWS

ในหน้าส่งออกจะมีตัวเลือกสองแบบ:
- เครื่องนี้: ใช้ตัวเข้ารหัสเดิมในเบราว์เซอร์ ไม่เสียค่าเรนเดอร์เซิร์ฟเวอร์
- เซิร์ฟเวอร์ AWS: อัปโหลด JSON โปรเจกต์ (รวมข้อมูลภาพ/เสียงที่ฝังไว้) ไป S3 แล้วใช้ Chromium บน AWS CodeBuild สร้างไฟล์วิดีโอ ก่อนให้ FFmpeg แปลงเป็น MP4 H.264/AAC หรือ ZIP หลายตอน

## วิธีติดตั้งครั้งแรก

ต้องมี Lambda ของระบบล็อกอินเดิม ติดตั้งผ่าน autodub/deploy.sh ใน AWS region เดียวกันก่อน

เปิด AWS CloudShell, clone repository branch main แล้วรันคำสั่งนี้จากโฟลเดอร์โปรเจกต์:

    bash cloud-export/deploy.sh https://main.d1wc6w01kiwpnk.amplifyapp.com

ใช้ URL เว็บไซต์จริงของโปรเจกต์หากเปลี่ยนโดเมน สคริปต์ติดตั้ง private S3 bucket พร้อมลบไฟล์หลัง 2 วัน, CodeBuild สำหรับเรนเดอร์, IAM permissions เฉพาะงาน, เพิ่ม Cloud API ให้ Lambda ที่ยืนยัน session และเปิดตัวเลือกใน AWS Amplify

**ต้องตั้งค่า AWS Budgets ก่อนเปิดใช้จริง** เพราะ CodeBuild, Lambda, S3 และ data transfer อาจมีค่าใช้จ่าย คิวเรนเดอร์จำกัดให้รันพร้อมกันสูงสุด 1 งาน และ timeout ต่อ build 120 นาที

## เพิ่มความเร็วและดูสถานะงานบน AWS

สำหรับโปรเจกต์ที่ติดตั้ง Cloud Export อยู่แล้ว ให้รันจาก AWS CloudShell หลังดึง main ล่าสุด:

    bash cloud-export/speedup.sh https://main.d1wc6w01kiwpnk.amplifyapp.com

สคริปต์นี้เปลี่ยน CodeBuild ที่มีอยู่เดิมให้ใช้ buildspec ที่ข้ามการติดตั้ง Playwright เมื่อมี cache, พยายามนำ Chromium และ npm cache กลับมาใช้ซ้ำในเครื่อง build เดิม และติดตั้ง browser system libraries เฉพาะเมื่อ Chromium ลองเปิดแล้วเปิดไม่ได้ (ไม่ต้องสร้าง CodeBuild/S3 ใหม่) พร้อมอัปเดต Lambda ให้รายงาน phase ของ CodeBuild และเริ่ม build หน้าเว็บใหม่

ข้อจำกัด:
- AWS ไม่รับประกันว่าแต่ละงานจะได้เครื่องเดิม; Local Cache เป็น best effort เท่านั้น
- โหมด WebM ผ่าน MediaRecorder ยังคงเรนเดอร์ **ตามเวลาจริง** (คลิปยาว 5 นาทีใช้เวลาอย่างน้อย 5 นาที) ก่อนแปลงเป็น MP4 ด้วย FFmpeg
- การส่งออกที่กำลังรันอยู่ไม่เปลี่ยนวิธีทำงานกลางคัน; การปรับปรุงจะเริ่มจากงานถัดไป
- หน้าเว็บจะระบุว่ากำลังต่อคิว ติดตั้งส่วนประกอบ หรือเรนเดอร์ รวมทั้งเวลาที่ผ่านไป (ไม่ใช่ ETA ที่รับประกัน)
- ถ้าต้องการลดเวลาต่ำกว่าความยาวคลิป จำเป็นต้องพัฒนาตัวเรนเดอร์แบบ offline frame encoding อีกชุดและตรวจเสียง/ซับใหม่ทั้งหมด

## การทำงานและข้อจำกัด

- ไม่เก็บ AWS secret ในโค้ดเว็บ การอัปโหลดใช้ signed URL อายุ 30 นาที และดาวน์โหลดใช้ signed URL อายุ 15 นาทีซึ่งขอใหม่ได้เมื่อกลับมาเข้าเว็บ
- โปรเจกต์/ผลลัพธ์ถูกลบจาก S3 ภายใน 2 วัน มีเพียง job ID ที่เก็บในเบราว์เซอร์เพื่อเรียกสถานะกลับมา
- เปิดโทรศัพท์ทิ้งไว้เฉพาะช่วงอัปโหลด เมื่อเริ่มงานบน AWS แล้วสามารถสลับแอปหรือปิดเว็บได้
- Server ไม่ fallback ไป CPU โทรศัพท์โดยอัตโนมัติหาก AWS ล้มเหลว
- ภาพ/เสียงที่เป็น URL ภายนอกต้องถูกเข้าถึงได้จาก AWS ด้วย ส่วน data URL ส่งไปพร้อมโปรเจกต์
- ปฏิเสธการส่งออกเมื่อฉากมีบทพากย์แต่ไม่มีคลิปเสียง และตรวจ output ว่าไม่เงียบเมื่อควรมีเสียง
- เวอร์ชันนี้ยังไม่ได้ทดสอบการทำงานจริงบน AWS ของผู้ใช้ ต้อง Deploy ก่อนแล้วลองตอนสั้นที่มีพากย์, ZIP หลายตอน และวิดีโอรวม
- การติดตั้ง Chromium และ FFmpeg ใน CodeBuild มี overhead เริ่มงาน โดยเฉพาะวิดีโอสั้น จึงไม่ได้รับประกันว่าเรนเดอร์เร็วกว่าทุกเครื่อง เพียงแต่ CPU/RAM เรนเดอร์จะไม่ทำงานบนโทรศัพท์
- หากต้องปิดระบบ: ตั้ง STORY_STUDIO_CLOUD_EXPORT=0 ใน Amplify และปิดสิทธิ์ StartBuild ที่ Lambda IAM role ไม่ใช่แค่ซ่อนปุ่ม

การ Merge โค้ดเข้ากับ GitHub อย่างเดียวไม่สามารถติดตั้งหรือเปิดใช้ทรัพยากร AWS แทนได้
