# Cinematic scenes A–E

Open these JSON projects through the existing project importer, or choose the same templates in **กำกับภาพ → กำกับ Cinematic**. They have no embedded audio; add narration or your own audio before a voiced export.

| File | Demonstration |
| --- | --- |
| street.json | A: wide street, camera pan/zoom, depth parallax |
| book.json | B: walk, reach, pickup, open/read, close, place |
| run.json | C: distance-driven run, camera follow, opening corridor door |
| forest.json | D: torch bound to hand, beam direction, fog and layered trees |
| school.json | E: wide school to student/window, turn, opening door |

`references/` contains measured, uncertain shot-boundary proposals from the three user-provided reference clips, not copied footage or trained model weights. Semantic fields deliberately remain unknown. See [the implementation guide](../../docs/CINEMATIC_ENGINE_TH.md).
